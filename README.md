# Portalolaranja

Vamos iniciar o desenvolvimento do PORTAL O LARANJA.

Nesta primeira etapa, quero construir exclusivamente a identidade visual e a estrutura-base do projeto.

OBJETIVO:
Criar a fundação visual de um portal profissional de notícias, moderno, elegante e responsivo, inspirado na experiência de navegação das redes sociais e nos grandes portais jornalísticos.

IDENTIDADE VISUAL:

Utilizar a logo oficial enviada como referência.

Utilizar o símbolo circular da laranja com folha como elemento secundário.

Utilizar o mascote 3D de blazer em espaços institucionais.

Preservar integralmente os arquivos originais da marca.

Utilizar o laranja oficial da identidade como cor de destaque.

Trabalhar com fundo escuro, preferencialmente grafite ou preto sofisticado.

Utilizar branco e cinza para textos.

Criar uma identidade visual consistente em todas as páginas.

ESTRUTURA VISUAL:
Criar:

Sistema de cores.

Tipografia.

Estilos de botões.

Estilos de cards.

Padrão de bordas e sombras.

Componentes reutilizáveis.

Layout responsivo para desktop, tablet e celular.

DIREÇÃO DE DESIGN:
Quero um visual de portal jornalístico premium, com aparência profissional, excelente legibilidade e navegação intuitiva.

O laranja deve ser utilizado estrategicamente para destacar informações importantes, botões, links e elementos da marca.

IMPORTANTE:

Não criar outra logo.

Não modificar o mascote.

Não utilizar cores aleatórias.

Não desenvolver ainda integrações externas.

Não criar funcionalidades administrativas nesta etapa.

Não configurar banco de dados ainda.

Não instalar recursos desnecessários.

Não reconstruir o projeto em etapas futuras sem necessidade.

Organize o código de forma modular e mantenha a identidade visual preparada para receber as próximas funcionalidades.

Ao finalizar, apresentar a estrutura visual criada e aguardar a próxima etapa.
